Multidimensional Arrays

অ্যারের ভেতরে অ্যারে — জটিল ডেটা সংগঠিতভাবে সংরক্ষণের পদ্ধতি

Multidimensional Array হলো এমন একটি অ্যারে যার প্রতিটি উপাদান নিজেই আরেকটি অ্যারে। এটি অ্যারের ভেতরে অ্যারে (Array of Arrays) — যেখানে ডেটাকে সারি ও কলামের মতো টেবিল বা ম্যাট্রিক্স আকারে সংরক্ষণ করা যায়।

ধরন
2D Array
অ্যারের ভেতরে একটি অ্যারে। সারি ও কলামে ডেটা রাখা যায়।
3D Array
অ্যারের ভেতরে অ্যারের ভেতরে আরও অ্যারে। ত্রিমাত্রিক ডেটা কাঠামো।
Mixed Array
Numeric ও Associative উভয় ধরনের কী একসাথে ব্যবহার করা যায়।
2D Array — সংখ্যাসূচক
Numeric 2D PHP 
$matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

// অ্যাক্সেস: [সারি][কলাম]
echo $matrix[0][1]; // 2
echo $matrix[2][0]; // 7

Associative Multidimensional Array
Associative 2D PHP 
$students = [
    ["name" => "Rahim",  "age" => 20, "city" => "Dhaka"],
    ["name" => "Karim",  "age" => 22, "city" => "Sylhet"],
    ["name" => "Fatema", "age" => 21, "city" => "Chittagong"],
];

// অ্যাক্সেস
echo $students[0]["name"]; // Rahim
echo $students[2]["city"]; // Chittagong

// foreach দিয়ে সব ডেটা দেখানো
foreach ($students as $student) {
    echo $student["name"] . " - " . $student["city"] . "\n";
}
3D Array উদাহরণ
3D Array PHP 
$school = [
    "class_1" => [
        "section_A" => ["Rahim", "Karim"],
        "section_B" => ["Fatema", "Nila"],
    ],
];

// অ্যাক্সেস
echo $school["class_1"]["section_A"][0];
// Output: Rahim

মনে রাখুন: যত গভীরে যাবেন, তত বেশি [] ব্র্যাকেট লাগবে। $arr[স্তর১][স্তর২][স্তর৩] — প্রতিটি ব্র্যাকেট একটি স্তর গভীরে যায়।
