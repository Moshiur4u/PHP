Associative Array

যেখানে প্রতিটি মানকে সংখ্যার বদলে অর্থপূর্ণ নাম দিয়ে সনাক্ত করা হয়

PHP-তে Associative Array হলো এমন একটি অ্যারে যেখানে প্রতিটি মানকে একটি স্ট্রিং বা নামযুক্ত কী (Key) দিয়ে পরিচিতি দেওয়া হয়, সংখ্যাসূচক সূচকের (Numeric Index) পরিবর্তে। এটি ডিকশনারি বা ম্যাপের মতো কাজ করে, যেখানে key => value ফরম্যাট ব্যবহার করা হয়।

প্রধান বৈশিষ্ট্য
তৈরি করা
array() ফাংশন বা ছোট ব্র্যাকেট [] সিনট্যাক্স ব্যবহার করে তৈরি করা হয়।
অ্যাক্সেস
সূচকের পরিবর্তে কী (Key) ব্যবহার করে মানগুলোতে পৌঁছানো হয়।
লুপ করা
foreach লুপ ব্যবহার করে কী এবং মান একসাথে অ্যাক্সেস করা যায়।
ব্যবহার
ইউজার প্রোফাইল, কন্টাক্ট লিস্ট বা অর্থপূর্ণ নামযুক্ত ডেটা সংগঠনে ব্যবহৃত।
কোড উদাহরণ
PHP 
// তৈরি করা
$student = [
    "name"  => "Rahim",
    "age"   => 20,
    "city"  => "Dhaka"
];

// অ্যাক্সেস
echo $student["name"]; // Rahim
echo $student["city"]; // Dhaka

// foreach লুপ
foreach ($student as $key => $value) {
    echo "$key: $value\n";
}
