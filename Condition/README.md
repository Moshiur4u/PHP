# PHP_Conditions

## If Condition

```bash
if ('condition') {
    # code...
}
```

## ifelse--------------

```bash

if ('condition') { # code...
} else { # code...
}
```

## ifelse if--------------

```bash
if ('condition') { # code...
} elseif ('condition') { # code...
} else { # code...
}
```

## switch--------------

```bash
switch ($variable) {
case 'value1': # code...
break;
case 'value2': # code...
break;
default: # code...
break;
}
```

## Ternary Operator--------------

```bash
$result = ('condition') ? 'value if true' : 'value if false';
```

## Null Coalescing Operator--------------

```bash
$value = $variable ?? 'default value';
```
