PHP Variable
Variable (ভেরিয়েবল)
PHP-তে ভেরিয়েবল হলো ডেটা সংরক্ষণের পাত্র। সবসময় $ চিহ্ন দিয়ে শুরু হয়।

ভেরিয়েবল হলো এমন একটি নামযুক্ত স্থান যেখানে ডেটা সাময়িকভাবে সংরক্ষণ করা হয়। PHP dynamically typed — আলাদা করে type ঘোষণা করতে হয় না।

String
টেক্সট ডেটা সংরক্ষণ করে।
$name = "Rahim";
echo $name;
Integer
পূর্ণসংখ্যা সংরক্ষণ করে।
$age = 20;
echo $age;
Float
দশমিক সংখ্যা সংরক্ষণ করে।
$price = 9.99;
echo $price;
Boolean
সত্য বা মিথ্যা মান ধরে।
$active = true;
$done = false;
NULL
কোনো মান নেই এটি বোঝায়।
$x = null;
Variable Variable
ভেরিয়েবলের নাম ডায়নামিকভাবে তৈরি করে।
$key = "city";
$$key = "Dhaka";
  • $ দিয়ে শুরু, তারপর অক্ষর বা আন্ডারস্কোর। সংখ্যা দিয়ে শুরু করা যাবে না।
  • PHP case-sensitive — $Name ও $name আলাদা ভেরিয়েবল।
  • নামে শুধু অক্ষর, সংখ্যা ও আন্ডারস্কোর ব্যবহার করা যাবে।
✓ $userName✓ $user_name✓ $_total ✗ $1name✗ $user-name✗ $my name
PHP Function
Function (ফাংশন)
ফাংশন হলো পুনর্ব্যবহারযোগ্য কোডের একটি ব্লক যা নির্দিষ্ট কাজ সম্পন্ন করে।

ফাংশন একবার লিখে বারবার ব্যবহার করা যায়। PHP-তে built-in ও user-defined দুই ধরনের ফাংশন আছে।

সাধারণ ফাংশন
parameter ছাড়া বা সহ ফাংশন তৈরি করা যায়।
function greet($name) {
  return "হ্যালো, " . $name;
}
echo greet("Rahim"); // হ্যালো, Rahim
Default Parameter
প্যারামিটারে ডিফল্ট মান দেওয়া যায়।
function greet($name = "বন্ধু") {
  return "হ্যালো, " . $name;
}
echo greet(); // হ্যালো, বন্ধু
Arrow Function (PHP 7.4+)
সংক্ষিপ্তভাবে anonymous ফাংশন লেখা যায়।
$double = fn($n) => $n * 2;
echo $double(5); // 10
Type Declaration (PHP 7+)
Parameter ও return type নির্দিষ্ট করা যায়।
function add(int $a, int $b): int {
  return $a + $b;
}
echo add(3, 4); // 7
মনে রাখুন: PHP ফাংশন নাম case-insensitive, তবে ভেরিয়েবল নাম case-sensitive।
PHP Constant
Constant (ধ্রুবক)
Constant হলো এমন একটি মান যা একবার নির্ধারণ করলে পরিবর্তন করা যায় না।

ভেরিয়েবলের মতো কিন্তু অপরিবর্তনীয়। সাধারণত নাম সব বড় হাতে লেখা হয়। $ চিহ্ন ব্যবহার করতে হয় না।

define() দিয়ে
যেকোনো জায়গায় constant তৈরি করা যায়।
define("PI", 3.1416);
echo PI; // 3.1416
const কীওয়ার্ড দিয়ে
Class-এর ভেতরে বা global scope-এ ব্যবহার হয়।
const SITE_NAME = "MyApp";
echo SITE_NAME;
Magic Constants
PHP-এর নিজস্ব built-in constant।
echo __LINE__; // লাইন নম্বর
echo __FILE__; // ফাইল পাথ
echo __DIR__; // ডিরেক্টরি
Class Constant
Class-এর ভেতরে constant তৈরি করা যায়।
class Math {
  const PI = 3.14;
}
echo Math::PI;
✓ define() — runtime-এ তৈরি করা যায় ✓ const — compile time-এ তৈরি হয় ✗ constant পরিবর্তন করা যায় না
PHP Loop
Loop (লুপ)
একই কাজ বারবার করার জন্য লুপ ব্যবহার হয়। PHP-তে ৪ ধরনের লুপ আছে।
for loop
নির্দিষ্ট সংখ্যকবার চালাতে হলে।
for($i=1; $i<=5; $i++) {
  echo $i . " ";
}
// 1 2 3 4 5
while loop
শর্ত সত্য থাকলে চলতে থাকে।
$i = 1;
while($i <= 5) {
  echo $i++;
}
do...while loop
অন্তত একবার চলবেই, তারপর শর্ত চেক করে।
$i = 1;
do {
  echo $i++;
} while($i <= 5);
foreach loop
অ্যারের প্রতিটি উপাদার নিয়ে কাজ করে।
$names = ["Rahim","Karim"];
foreach($names as $n) {
  echo $n;
}
break
লুপ বন্ধ করে বের হয়ে যায়।
for($i=1;$i<=10;$i++){
  if($i==5) break;
  echo $i;
} // 1234
continue
বর্তমান iteration বাদ দিয়ে পরেরটায় যায়।
for($i=1;$i<=5;$i++){
  if($i==3) continue;
  echo $i;
} // 1245
If / Else
If Else & Nested If Else
শর্ত অনুযায়ী ভিন্ন কোড চালানোর জন্য if-else ব্যবহার হয়।
if / else if / else
একাধিক শর্ত পরীক্ষা করে সিদ্ধান্ত নেয়।
$marks = 75;
if($marks >= 80) {
  echo "A+";
} elseif($marks >= 70) {
  echo "A"; // এটি প্রিন্ট হবে
} else {
  echo "B";
}
Nested If Else
if-এর ভেতরে আরেকটি if — জটিল শর্তের জন্য।
$age = 20; $citizen = true;
if($age >= 18) {
  if($citizen) {
    echo "ভোট দিতে পারবেন";
  } else {
    echo "নাগরিক নন";
  }
} else {
  echo "বয়স কম";
}
Logical Operators দিয়ে
&& (এবং), || (অথবা), ! (না) ব্যবহার করে শর্ত যুক্ত করা যায়।
if($age >= 18 && $citizen == true) {
  echo "যোগ্য";
}
PHP OOP
Object Oriented Programming
OOP হলো class ও object ব্যবহার করে কোড সংগঠিত করার পদ্ধতি।
Class ও Object
Class হলো blueprint, Object হলো তার বাস্তব রূপ।
class Student {
  public $name;
  public $age;
  function info() {
    return $this->name . ", " . $this->age;
  }
}
$s = new Student();
$s->name = "Rahim";
echo $s->info();
Constructor ও Destructor
Object তৈরি ও মুছে যাওয়ার সময় স্বয়ংক্রিয়ভাবে চলে।
class Car {
  function __construct($model) {
    $this->model = $model;
  }
  function __destruct() {
    echo "শেষ!";
  }
}
$c = new Car("Toyota");
Inheritance (উত্তরাধিকার)
Parent class-এর বৈশিষ্ট্য child class পায়।
class Animal {
  function speak() { echo "..."; }
}
class Dog extends Animal {
  function speak() { echo "ঘেউ!"; }
}
$d = new Dog();
$d->speak();
Access Modifier
property বা method-এর প্রবেশাধিকার নিয়ন্ত্রণ করে।
class Person {
  public $name; // সবাই দেখতে পাবে
  protected $age; // child-ও দেখবে
  private $pass; // শুধু এই class
}
Switch Case
Switch Case Statement
একটি ভেরিয়েবলের একাধিক সম্ভাব্য মান পরীক্ষা করতে switch ব্যবহার হয়।

অনেক elseif লেখার পরিবর্তে switch ব্যবহার করলে কোড পরিষ্কার থাকে। প্রতিটি case-এ break না দিলে পরের case-এও চলতে থাকে।

সাধারণ switch
একটি মানের বিপরীতে একাধিক case পরীক্ষা করে।
$day = "শুক্র";
switch($day) {
  case "শুক্র":
    echo "ছুটির দিন";
    break;
  case "শনি":
    echo "অর্ধদিন";
    break;
  default:
    echo "কাজের দিন";
}
একাধিক case একসাথে
একই কাজের জন্য একাধিক case একত্রিত করা যায়।
$grade = "B";
switch($grade) {
  case "A":
  case "A+":
    echo "চমৎকার!";
    break;
  case "B":
    echo "ভালো!"; // এটি
    break;
}
সতর্কতা: break না দিলে পরের case-ও execute হবে — এটিকে "fall-through" বলে।
Ternary Operators
Ternary ও Nested Ternary Operators
if-else-এর সংক্ষিপ্ত রূপ। এক লাইনে শর্তীয় মান নির্ধারণ করে।

Ternary operator হলো শর্ত ? সত্য_হলে : মিথ্যা_হলে — তিনটি অংশ থাকে বলে এর নাম ternary।

সাধারণ Ternary
শর্ত অনুযায়ী দুটি মানের একটি বেছে নেয়।
$age = 20;
$status = ($age >= 18) ? "প্রাপ্তবয়স্ক" : "অপ্রাপ্তবয়স্ক";
echo $status; // প্রাপ্তবয়স্ক
Null Coalescing (??) — PHP 7+
মান null বা অনির্ধারিত হলে ডিফল্ট মান দেয়।
$name = $_GET["name"] ?? "অতিথি";
echo $name; // name না থাকলে: অতিথি
Nested Ternary
Ternary-এর ভেতরে আরেকটি ternary — একাধিক শর্তের জন্য।
$marks = 75;
$grade = ($marks >= 80) ? "A+"
       : (($marks >= 70) ? "A"
       : (($marks >= 60) ? "B" : "C"));
echo $grade; // A
Elvis Operator (?:)
মান সত্য হলে নিজেই ফেরত দেয়, না হলে বিকল্প মান।
$name = "";
$display = $name ?: "নাম নেই";
echo $display; // নাম নেই
পরামর্শ: Nested ternary বেশি জটিল হলে if-else ব্যবহার করা ভালো — কোড পড়তে সহজ হয়।
